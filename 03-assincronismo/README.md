# Manipulação do DOM

## Seleção: 
Use document.getElementById ou document.querySelector.

## Eventos: 
Use element.addEventListener('click', funcao) para reagir a cliques e ações do usuário.

## Alteração: 
Mude textos com element.textContent ou estilos com element.style.

AssincronismoPromessas (Promises): Representam um valor que pode estar pronto no futuro (pending, resolved, rejected).Async/Await: Maneira moderna e limpa de escrever código assíncrono pausando a execução até a resposta chegar.
